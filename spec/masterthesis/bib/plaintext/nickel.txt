== https://nickel-lang.org/user-manual/merging (summary of fetched page)
"Merge is a **symmetric** operation."
Fields of equal priority are merged recursively; "If the priorities differ, the value with the highest priority simply erases the other."
`default` = lowest priority ("can be used to provide a base value, but have it be overridable through merging"); `force` = highest ("can never be overridden").
Equal-priority, non-mergeable values: error "Merge operands have the same merge priority but they can't be combined." ("Number values can only be merged if they are equal.")
No left/right-biased override operator is described; `&` is the only merge operator.

== https://nickel-lang.org/user-manual/typing
"Nickel is gradually typed, meaning you can mix both static typing and dynamic typing."
"To express such constraints, Nickel features row polymorphism."
